# 3826 community profile

This repository hosts the public GitHub organization profile for
[thirtyeighttwentysix](https://github.com/thirtyeighttwentysix).

- `profile/README.md` is the organization landing page.
- `profile/assets/` contains editable SVG banners, project cards, and the avatar.
- `scripts/generate-assets.mjs` reproduces the SVG assets with Node.js, without dependencies.

Run `node scripts/generate-assets.mjs` after changing the artwork. GitHub selects
the light or dark hero using the visitor's color scheme. Every image has meaningful
alternative text, and the projects and documentation are linked as text as well.

The Volan mark is a vector rendition of the logo supplied by the project owner,
reused from `volan-idea/assets/logo-mark.svg`. Keep its silhouette intact.

Palette: ivory `#F5F3ED`, graphite `#17191D`, lime `#D7FF62`.
